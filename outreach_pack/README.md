## 朝の手順（1団体あたり）
1. `soufujo_XX.html` をブラウザで開き印刷（またはPDF→印刷）
2. 同封サンプルを印刷：`https://samples-topaz.vercel.app/<slug>/` を開き**カラー印刷**（フルページ）
3. 送付状＋サンプル印刷を封入 → `宛名ラベル.html` の該当ラベルを貼付 → 投函
4. 送付した団体を管理ツール `/sales`（リード管理）に記録（送付日・状態）
