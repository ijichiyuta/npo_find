# NPO法人「ホームページなし」営業リスト作成ツール

内閣府 NPO法人ポータルサイトの公開データから、**活動中でホームページを持っていない(または検索しても出てこない)NPO法人**を抽出し、ホームページ制作の営業リストを作るツール一式。

## 全体の流れ

```
[Stage 1] npo_leads.py   公開データからHP未登録・活動中の法人を抽出 → CSV
     ↓
[Stage 2] verify_web.py  各法人をWeb検索し「本当にサイトが無い/SNSのみ/実はある」を判定
     ↓
[営業]    見つからず(有力リード) の法人にサンプルHPを添えて提案
```

## データ元

内閣府 NPO法人ポータルサイト「法人情報の一括ダウンロード」
<https://www.npo-homepage.go.jp/npoportal/download/all>

- `gyousei_000.zip` … **行政入力情報**(全国): 法人名/所在地/代表者/活動分野/解散情報/法人番号 等
- `houjin_000.zip` … **法人入力情報**(全国): 電話/FAX/**ホームページ**/メール/決算 等
- 2つのCSVは行順が完全一致しており、行番号で確実に結合できる。
- スクリプト初回実行時に `data/` へ自動ダウンロード・展開する。

## Stage 1: リード抽出 `npo_leads.py`

```bash
# まず件数の分布を見る(所轄庁別・活動分野別)
python3 npo_leads.py --stats

# 全国のHP未登録・活動中をすべて出力
python3 npo_leads.py

# 都道府県で絞る(政令市も親県に含めて抽出)
python3 npo_leads.py --pref 東京都
python3 npo_leads.py --pref 神奈川          # 横浜市/川崎市/相模原市も含む

# 活動分野で絞る(番号1-20 または キーワード。カンマ区切りでOR)
python3 npo_leads.py --pref 神奈川 --field 子ども
python3 npo_leads.py --pref 大阪 --field 13,福祉

# SNS/無料ブログのみの法人も営業対象に含める
python3 npo_leads.py --pref 東京都 --include-sns

# 設立が新しい法人だけ / 件数上限 / 出力先指定
python3 npo_leads.py --pref 東京都 --established-after 2018 --limit 300 --out tokyo_new.csv
```

主なオプション:

| オプション | 説明 |
|---|---|
| `--pref 名` | 都道府県で絞る(政令市も親県に含む) |
| `--area 名` | 所轄庁そのもので絞る(例: 横浜市だけ) |
| `--field 指定` | 活動分野。番号(1-20)またはキーワード、カンマ区切りOR |
| `--keyword 語` | 法人名・事業目的に含む語で絞る |
| `--established-after 年` | その年以降に設立認証された法人のみ |
| `--include-sns` | 登録HPがSNS/ブログのみの法人も含める |
| `--include-registered` | HP登録済みも含める(通常は除外) |
| `--limit N` | 出力上限 |
| `--stats` | 抽出せず件数分布のみ表示 |
| `--out パス` | 出力先(既定 `output/leads_<条件>.csv`) |

## Stage 2: 「検索しても出てこない」を判定 `verify_web.py`

HP未登録でも実際にはサイトを持つ法人がいるため、各法人名をWeb検索して分類する。

```bash
python3 verify_web.py output/leads_神奈川_分野子ども.csv --limit 100
python3 verify_web.py output/leads_東京都.csv --limit 200 --only-missing
```

判定は `Web確認結果` 列に入る:

- `独自サイトあり` … 既にサイトがある(営業対象外にできる)
- `SNS・ブログのみ` … SNSだけ。きちんとしたHPが無く営業余地あり
- `見つからず(有力リード)` … 検索で出てこない = **最有力の営業先**

### 検索エンジンの設定(2通り)

**方法A: Google Custom Search API**(自動・自分で回す)
無料枠100クエリ/日、以降 $5/1000件。
1. <https://programmablesearchengine.google.com/> で検索エンジンを作成(「ウェブ全体を検索」ON)→ 検索エンジンID(cx)
2. <https://developers.google.com/custom-search/v1/introduction> で APIキー取得
3. 環境変数を設定して実行:
   ```bash
   export GOOGLE_API_KEY="＜APIキー＞"
   export GOOGLE_CSE_ID="＜検索エンジンID＞"
   python3 verify_web.py output/leads_東京都.csv --limit 200
   ```

**方法B: Claudeに依頼**(APIキー不要)
Stage 1 のCSVを指定して「このリストをWeb検証して有力リードだけ残して」と依頼すれば、
Claude が検索して `Web確認結果` を埋める。数百件規模まで。

> 検索結果は `data/web_cache.json` にキャッシュされ、再実行時は再検索しない。

## ディレクトリ構成

```
npo_find/
├── npo_leads.py       # Stage 1: 抽出
├── verify_web.py      # Stage 2: Web検証
├── data/              # 公開データ(自動DL)・検索キャッシュ
├── output/            # 生成した営業リストCSV
└── README.md
```

## 注意

- データは公開情報。**個人情報保護・特定商取引法・各種法令の範囲内**で利用すること。
- 出力に含まれる代表者名・所在地は営業目的の適正な範囲で扱う。
- 検索エンジンへの過度なアクセスは避け、APIの利用規約に従う。
- データは随時更新されるため、定期的に `data/` を削除して再取得すると最新になる。
