## コンプライアンス（3サイト共通で実装済み）

- 本文は公開情報（NPOポータルの定款目的・所在地・代表者名、あすはるは公開連絡先と定員）の範囲のみ
- 実績数値・活動報告・あいさつ文などのダミーは、画面上に「※サンプル」表記+HTMLコメントで明記
- あすはるの定員（20名/2名）と設立年のみ実データ（出典を画面に記載）
- 受賞・提携などの虚偽記載なし／相手のロゴ不使用／写真はUnsplash（商用可）のイメージで「差し替えポイント」コメント付き
- noindex設定済み・フォームはデモ動作（送信されない旨を表示）
- フッターに「ご提案用サンプルです」の明記+スマートコネクトのクレジット

## 営業での使い方

1. スクリーンショットを印刷して郵送DMに同封（「御団体向けに試作しました」）
2. 反応があったらブラウザで実物を見せる（またはその時点で一時URLに公開）
3. **注意: 実在団体名を含むため、先方の了承前にインターネット公開しないこと**（見せる時はローカル表示か、限定URLで）
